# Meta Glass Converter 🕶️

A high-performance client-side web tool to convert JPG photos to **3024×4032**, inject authentic **Ray-Ban Meta Smart Glasses 2 / Meta AI** EXIF metadata, clean sensitive data (such as GPS and serial numbers), automatically copy Base64 to clipboard, and download converted JPG files.

## ⚡ Features
- **All-In-One 1-Click Action:** Convert, copy Base64 & download in a single tap.
- **Ray-Ban Meta Specs:** Automatically resizes & orients images to `3024 × 4032`.
- **EXIF Cleanup & Injection:** Injects `Meta AI` and `Ray-Ban Meta Smart Glasses 2` tags while stripping location/device tracking info.
- **100% Client-Side:** Everything is processed inside the browser using HTML5 Canvas & piexifjs. Zero server uploads.
